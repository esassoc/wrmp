Metric card — data-link studies

Three treatments of the topic-page metric card, each joining the round-3 exhibit family — the same format chips, scope metadata, and Data / Tools / Context vocabulary as the exhibit end-card hub, brought down to card scale. Every treatment is dataset-forward: it links to a specific data-catalog dataset, not to tools broadly. The three explore how much of the exhibit's data-hub to carry, and how prominent the dataset link should be.

How the dataset surfaces

One compact dataset row, a small categorized hub, or a single dataset action leading the card.

Category-chip density

A single Data item, or the full Data / Tools / Context grouping with counts, carried down from the exhibit hub.

Primary affordance

Whether the card leads with viewing the figure or with getting the data — and how far the figure chrome recedes.

Three treatments · one metric

The same metric — Native vs. invasive fish composition — rendered three ways, so the axes compare directly. It carries a dataset (Species catalog), a tool (EcoAtlas), and a data story (the Native vs. Invasive exhibit).

Minimal change: one compact hub-item at the foot of the card, pointing at the specific dataset. Figure downloads demote to a quiet line. Tests whether a single row carries the family without a full panel.
